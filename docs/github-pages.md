# Публичный просмотр через GitHub Pages

GitHub Pages публикует только `public-preview/`. Python-сервер и админка
работают отдельно, при запуске `server.py` на сервере.

В версии для просмотра доступны видео, анимация, текущий снимок афиши,
опубликованные альбомы, просмотр фотографий и скачивание оригиналов/ZIP.
Покупка билетов ведёт на сайт соответствующего продавца.

На GitHub Pages афиша и фото — снимок на момент экспорта. Локальные загрузки
и обновления серверной афиши попадут туда после нового экспорта и отправки
изменений в GitHub. В полной серверной версии афиша обновляется автоматически.

Для обновления создайте экспорт в **новой пустой папке**:

```sh
python3 tools/export_preview.py --output /tmp/spot-preview-new
```

Для сохранения оригиналов актуальных афиш перед экспортом запустите
`python3 tools/cache_preview_posters.py` (нужны Pillow и curl). Картинки
копируются без изменения размера и качества.

Проверьте результат, замените содержимое `public-preview/` новым экспортом,
затем закоммитьте и отправьте изменения в `main`. GitHub Actions развернёт
только `public-preview/`.

Экспорт читает только опубликованные альбомы. `.spot-data/`, логин/хеш пароля,
сессии, база SQLite и черновики не включаются. Опубликованные фотографии
в публичном репозитории остаются в истории Git даже после удаления из сайта.
